# Blind review of C.py (= CodeReclaimers 58311e4a, the version the judges reviewed; rank 1 is the older d83efe07)
Classification: (a) hard-codes the target algorithm. Score 2/10.
- Mechanism: a hand-built residue-number (CRT) solver wrapped in learned bookkeeping.
  - Prompts parsed to integers by place value (459-479); the reversed N is never decoded, only used as an opaque registry key.
  - Per-(T-slot, prime) low-rank tables E·w trained by CE on label residues y mod p (989-999, 1920).
  - After 1,200 steps a detector scores six author-written maps r + D·r(r−1)/2 (D=0..5; D=2 is squaring) against the tables and latches a winner. Eval then ignores the tables: it computes the formula map for 564 primes, composes it by binary exponentiation over T's bits, takes each N's factor primes from no_grad agreement statistics, reconstructs by brute-force CRT, and writes digits by place value.
  - Unseen N go through a lookup built from 159 enumerated encodings, digit reversal among them.
- Rule 7 violation (no trainable parameter reaches eval logits after detection). Rule 8 violation (eval is integer gathers/argmax; training logits a 17x17 bias lookup, tied to the real parameters only by terms multiplied by zero; E_exact, 53.5M params, never trains, a rule-6 problem too). Rule 9 violation at training time (CPU Python alias fitting, table materialization over ~159k prime pairs, T-decomposition search, law maps; `_stream` state in Python dicts). 12/14 violation: hidden no_grad training in the loss (latching, D-selection, law probes, alias fits, table builds), cross-batch data inspection (N/T registries, per-identity max label), embedded task-specific solvers. Gradient targets come from labels, but the eval-deciding gate compares the code's own x^(2^T) mod p with labels; unseen-N entries computed from author formulas.
- For: the only gradient targets are label residues; squaring chosen because it matches tables learned from labels; reversed N's factors from label agreement; fallback T-composition law probed, not fixed.
- Against: once D is chosen every stage is author code (closed-form squaring mod p, binary exponentiation, CRT, decimal decoding); candidates built so D=2 is squaring; codec bank contains digit reversal; trained parameters never touch eval logits.
